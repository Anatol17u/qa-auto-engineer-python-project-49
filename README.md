# Игры разума (Python)

[![hexlet-check](https://github.com/Anatol17u/qa-auto-engineer-python-project-49/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Anatol17u/qa-auto-engineer-python-project-49/actions)

Погрузитесь в экосистему Python и научитесь настраивать рабочее окружение. Подружитесь с менеджером зависимостей и линтером. Поймете, чем git отличается от GitHub, поработаете с внешними репозиториями. Получите опыт построения архитектуры полноценного приложения и написания чистого кода.

Учебный проект Хекслета: https://ru.hexlet.io/programs/qa-auto-engineer-python
Как это должно работать: https://asciinema.org/a/l40Lrk3midkLmNEOmgZErGnY7

## Стек

- Python (версия 3.12 или выше)
- Пакетный менеджер 'uv' если он не устанволениспользуйте инструкцию: https://docs.astral.sh/uv/getting-started/installation/

## Установка

1. Склонируйте репозиторий:

git clone https://github.com/Anatol17u/qa-auto-engineer-python-project-49.git
cd qa-auto-engineer-python-project-49

2. Установите зависимости: 
make install
3. Соберите и установите пакет в систему: 
make build
make package-install
